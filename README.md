# ระบบรายงานอุบัติการณ์ (Incident Report)

ระบบบันทึกเหตุการณ์ไม่คาดคิด อุบัติเหตุ ความผิดพลาด และข้อร้องเรียน แทน Google Form เดิม
โครงสร้างเดียวกับระบบแจ้งซ่อม: หน้าเว็บบน GitHub Pages + Google Apps Script + Google Sheets

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ วางใน Apps Script ของ Google Sheets |
| `index.html` | หน้าเว็บทั้งหมด (แจ้งเหตุ, ภาพรวม, รายการ, ตั้งค่า) |
| `config.js` | ใส่ลิงก์เว็บแอป Apps Script |
| `manifest.webmanifest`, `sw.js`, `*.png` | ให้ติดตั้งเป็นแอปบนมือถือได้ (Add to Home Screen) |

## ขั้นตอนติดตั้ง (ประมาณ 15 นาที)

### 1. ติดตั้งฝั่ง Google Sheets
1. เปิดไฟล์ Google Sheets **Incident Report (การตอบกลับ)** ที่ใช้อยู่
2. เมนู **ส่วนขยาย > Apps Script** ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาไฟล์ `Code.gs` จากชุดนี้ทั้งหมด กดบันทึก
3. เลือกฟังก์ชัน **setup** ที่แถบด้านบน แล้วกด **เรียกใช้** อนุญาตสิทธิ์ตามที่ Google ถาม
   - ระบบจะสร้างชีต `IR_Incidents`, `IR_Users`, `IR_Settings` และโฟลเดอร์เก็บรูปใน Google Drive
   - ดึงข้อมูลทั้งหมดจากชีต `จาก ภายใน` (คำตอบฟอร์มเดิม) เข้ามาในรูปแบบใหม่ โดย **ไม่แก้ไขชีตเดิม**
   - สร้างผู้ใช้เริ่มต้น `admin` / `admin1234` → **เปลี่ยนรหัสผ่านทันทีหลังเข้าระบบครั้งแรก**
4. (แนะนำ ระหว่างช่วงเปลี่ยนผ่าน) เรียกใช้ฟังก์ชัน **installFormSync** ครั้งเดียว
   ถ้ายังมีคนส่ง Google Form เดิม ข้อมูลจะถูกดึงเข้าระบบใหม่อัตโนมัติ
5. **การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด ทำให้ใช้งานได้ แล้วคัดลอก **URL ของเว็บแอป** (ลงท้าย `/exec`)

> แก้โค้ดภายหลัง: การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข (ไอคอนดินสอ) > เวอร์ชัน: เวอร์ชันใหม่
> เพื่อให้ URL เดิมยังใช้ได้

### 2. ขึ้นหน้าเว็บบน GitHub Pages
1. สร้าง repository ใหม่ เช่น `larepong-create/incident` (แบบเดียวกับ `repair`)
2. แก้ `config.js` ใส่ URL จากข้อ 1.5
   ```js
   window.APP_API_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
   ```
3. อัปโหลดทุกไฟล์ในชุดนี้ (ยกเว้น `Code.gs` และ `README.md` ไม่จำเป็น)
4. Settings > Pages > Branch: `main` / root > Save
5. เปิด `https://larepong-create.github.io/incident/` เข้าสู่ระบบด้วย `admin`

### 3. ตั้งค่าในระบบ (เมนู ตั้งค่า)
- เพิ่มผู้ใช้ให้ผู้บริหาร/QA (เห็นทุกสาขา) และหัวหน้าสาขา (เห็นเฉพาะสาขาตัวเอง)
- ปรับรายการสาขา ประเภท หมวดปัญหา แผนก ได้เอง
- **รหัสแจ้งเหตุ** (ไม่บังคับ): ถ้าตั้งไว้ พนักงานต้องกรอกรหัสนี้ครั้งแรกก่อนแจ้งเหตุ กันคนนอกที่ได้ลิงก์ไป
- **แจ้งเตือน LINE**: สร้าง LINE Official Account ที่ LINE Developers (Messaging API)
  เชิญบอทเข้ากลุ่มผู้บริหาร แล้วใส่ Channel access token และ Group ID เลือกระดับขั้นต่ำที่ต้องการให้แจ้ง

### 4. แจ้งพนักงาน
- ส่งลิงก์ `https://larepong-create.github.io/incident/` ในกลุ่ม LINE พนักงาน แนะนำให้กด **เพิ่มไปยังหน้าจอหลัก**
- พนักงานแจ้งเหตุได้โดย **ไม่ต้องเข้าสู่ระบบ** ระบบจำชื่อและสาขาไว้ในเครื่อง
- เมื่อใช้งานได้ดีแล้ว ปิดการรับคำตอบใน Google Form เดิม

## สิ่งที่เปลี่ยนจาก Google Form

| เดิม | ระบบใหม่ |
|---|---|
| พิมพ์สาขา/แผนก/เวลาเอง ข้อมูลไม่สม่ำเสมอ (`Front`, `เวช`, `17.36น.`, `18.4`) | เลือกจากปุ่ม เวลาเป็นรูปแบบเดียว นำไปทำกราฟได้ |
| ไม่มีระดับความรุนแรง | 4 ระดับ ตั้งแต่เกือบเกิดเหตุถึงรุนแรง |
| มูลค่าเคลมเป็นข้อความ (`เคลม ราคา 1,840 บาท`) | ช่องตัวเลข รวมยอดได้ |
| การดำเนินการ/ลงชื่อ พิมพ์ต่อท้ายในชีต | บันทึกเป็นลำดับเหตุการณ์ พร้อมสถานะ รอรับเรื่อง → กำลังดำเนินการ → ปิดเรื่อง |
| ไม่มีรูปภาพ | แนบรูปได้ 6 รูป (ย่อขนาดอัตโนมัติ เก็บใน Google Drive) |
| ไม่มีภาพรวม | Dashboard แยกประเภท หมวด แผนก สาขา ระดับ ช่วงเวลา และเรื่องที่ต้องติดตาม |
| ทุกคนเห็นทุกเรื่อง | สิทธิ์ตามบทบาท และตั้งเรื่องเป็นความลับได้ |

## เลขที่เรื่อง
รูปแบบ `IR` + ปี พ.ศ. 2 หลัก + เดือน + ลำดับ เช่น `IR6910-047` = เรื่องที่ 47 ของ ต.ค. 2569
เปิดตรงไปที่เรื่องได้ด้วย `…/incident/#IR6910-047`

## หมายเหตุ
- ข้อมูลจริงอยู่ในชีต `IR_Incidents` เปิดดู กรอง หรือดาวน์โหลดเป็น Excel ได้ตามปกติ
  คอลัมน์ `บันทึกการดำเนินการ` และ `ไฟล์แนบ` เก็บเป็น JSON อย่าแก้ด้วยมือ
- หมวดปัญหาและระดับของข้อมูลเดิมระบบเดาจากข้อความ ผู้บริหารแก้ได้ที่ปุ่ม **แก้ไขการจัดหมวด** ในแต่ละเรื่อง
- ถ้าเปิดหน้าเว็บโดยยังไม่ใส่ URL ใน `config.js` จะเป็นโหมดตัวอย่าง (ข้อมูลเก็บในเบราว์เซอร์เท่านั้น)
